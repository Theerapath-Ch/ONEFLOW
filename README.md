# Oneflow

Oneflow is a web platform for discovering and exploring digital tools and products.

The project is currently under development. The initial goal is to build a simple and modern platform where users can browse tools, search for products, and explore different categories.

## Status

Work in Progress

The project is still in the early development stage. Features, structure, and design may change as development continues.

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Lucide React

## Current Features

- Product / tool listing
- Category filtering
- Search
- Responsive UI
- Dark theme
- Animated hero section
